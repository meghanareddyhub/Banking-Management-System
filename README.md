Banking Management System 
A Python-based banking application integerated with MySQL for managing cutsomer accounts, balances, depositis, withdrawals, and transaction records.

Features 
- Customer registration and account creation
- Password-based login and authentication
- Balance enquiry
- Deposit and withdrawal operations
- Transaction history
- Customer and account management
- MySQL database integration
- Session-based user operations

Technologies Used

- Python
- MySQL
- SQL
- mysql-connector-python

Database

The application uses MySQL to store and manage:

- Customer details
- Account information
- Banking transactions

The database were created and managed through MySQL during development.
